# Grand Hotel

A boutique upscale hotel website — single-page, responsive, and ready to deploy with zero build step.

🔗 Repository: https://github.com/Mohammed276-wq/Grand-hotel-Restaurant-web

## Stack

- HTML5 (semantic, accessible markup)
- Tailwind CSS (via CDN)
- Vanilla JavaScript
- Google Fonts (Playfair Display + Inter)

## Structure

```
index.html      Main page — all sections
css/style.css   Custom styles beyond Tailwind utilities
js/main.js      Nav toggle, scroll animations, booking form, gallery lightbox, newsletter form
```

## Running locally

No build step required — just open `index.html` in a browser, or serve the folder with any static file server.

## Deploying

Drag-and-drop the project folder onto [Netlify](https://app.netlify.com/drop) or [Vercel](https://vercel.com/new), or connect this repository directly for continuous deployment.
